## 프로젝트 위치와 실행 주소

- 저장소 안 게임 폴더: `survivor-run/`
- 공개 게임 주소: https://sowol244.github.io/mobile-game/survivor-run/
- 진입 파일: `survivor-run/index.html`
- 빌드 없이 정적 파일로 실행합니다.

## 현재 코드 상태

- 게임 코드는 `main`의 `e041fb4` (`Improve survivor support and combat visuals`)에 있습니다. 작업 시작 당시 `main`과 `origin/main`은 일치했고 작업 트리는 깨끗했습니다.
- 이 인수인계는 `survivor-run/`만 다룹니다. 이어서 작업할 때 저장소의 다른 게임과 파일은 변경하지 마세요.
- 브라우저 캐시 갱신 표식은 `1-1-20261014v`입니다. `index.html`, `main.js`, `render.js`의 모듈 주소에 반영되어 있습니다.

## 최근 반영 사항

- 새 배경 이미지 `assets/roadside-backdrop.webp`와 도로변 폐허·차량·가드레일 묘사를 추가했습니다.
- 드럼통 보상 표식을 분리하고 겹침을 줄여 목표 보상을 알아보기 쉽게 했습니다.
- 지원 생존자를 작게 조정하고 달리기 프레임, 흔들림, 발 먼지 효과와 총구 위치를 적용했습니다.
- 보스의 좌우 이동·호흡·흔들림·돌진 모션을 보강하고 공격 자세 이미지를 추가했습니다. 경고 전조는 62초, 보스 시작은 64초입니다.
- 폭발 드럼통에 불꽃 섬광, 파편, 불티, 충격 링을 넣고 폭발 효과가 더 오래 보이게 했습니다.
- 캐릭터/배경 추가 에셋: `assets/support-survivor-run.webp`, `assets/support-survivor-b-run.webp`, `assets/zombie-brute-attack.webp`.

## 실행 및 조작

저장소 루트에서 정적 서버를 실행하세요.

```powershell
python -m http.server 8000
```

브라우저에서 `http://127.0.0.1:8000/survivor-run/`을 여세요.

- 마우스 또는 터치 드래그: 좌우 이동
- 키보드 좌우 화살표: 좌우 이동
- 사격은 자동입니다. 플레이어 위치를 바꿔 적이나 보급통의 공격 목표를 조정합니다.

## 확인 결과와 미해결 사항

- Codex 내부 브라우저에서 로컬 시작 화면과 전투 장면을 확인했습니다. 보상 표식의 겹침, 지원 생존자의 크기와 달리기, 새 배경, 폭발 효과를 확인했습니다.
- 보스 공격 자세는 로컬 미리보기에서 확인했습니다. 확인을 위해 잠시 바꿨던 타이밍 값은 복구되어 실제 설정은 경고 62초/등장 64초입니다.
- 자동화 브라우저가 백그라운드에서 느려져 한 판 전체를 안정적으로 끝까지 확인하지 못했습니다. 긴 플레이와 보스전의 실제 흐름은 다시 확인해야 합니다. 자동화 테스트 스위트는 실행하지 않았습니다.
- 푸시 후 공개 주소를 강력 새로고침해도 이전 전투 렌더러가 표시됐습니다. 새 배경 이미지 파일은 공개 경로에서 응답했으므로, 게임 모듈 배포본이나 GitHub Pages 산출물/캐시가 최신인지 추가 확인이 필요합니다. 현재 코드 커밋 자체는 `origin/main`에 올라가 있습니다.
