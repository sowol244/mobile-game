# 모바일 게임 작업실

GitHub Pages에서 제공하는 모바일 HTML 게임 모음입니다.

- `arena-duel/` 아레나 결투: 1대1 결투와 협동 보스전
- `meteor-dodge/` 스타 슈터: 우주 슈팅 게임
- `super-jump/` 교행이의 모험: 스테이지형 액션 게임
- `lumagrid/` LumaGrid: 8×8 블록 퍼즐, 이어하기와 온라인 최고 기록
- `gravibreak/` GraviBreak: 중력 방향을 바꾸는 퍼즐과 무한 모드, 오늘의 도전
- `sudoku/` 숫자 정원: 100개의 숫자 퍼즐
- `lightshade/` Lightshade: 빛을 활용하는 80개 스테이지 퍼즐

각 게임은 독립된 정적 HTML과 JavaScript 모듈로 실행됩니다. 저장 데이터는 브라우저에 보관하며, 최고 기록은 Supabase 온라인 순위표에 저장합니다.
