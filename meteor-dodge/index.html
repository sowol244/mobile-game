게임 설명

  • 이동 왼쪽 조이스틱으로 움직여요. (PC: 방향키)
  • 공격 연사 버튼을 누르고 있으면 미사일이 계속 나가요. (PC: Space)
  • 아이템 파란 P를 먹을 때마다 미사일이 4단계까지 강해져요. 맞으면 한 단계 약해지고, 4단계일 때는 P가 드물게 나와요.
  • 폭탄 아이템 붉은 B는 폭탄이에요. 스테이지마다 딱 2개만 나와요.
  • 폭탄 위기일 때 폭탄 버튼으로 화면의 적과 총알을 싹 지워요. (PC: B)
  • 스테이지 시작은 PHASE 1, 1분에 PHASE 2, 3분에 PHASE 3, 4분이 되면 보스가 나타나요. 보스를 쓰러뜨리면 다음 스테이지, 총 3탄이에요.
  • 기록 분마다 최고 점수가 기록돼요.
