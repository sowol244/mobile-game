# 대난투 아레나 — 기획서 (v0.3)

> 브롤스타즈 같은 **탑뷰 실시간 난투 게임**을 휴대폰 브라우저용 싱글 플레이로 만든다.
> 상대와 아군은 모두 컴퓨터(봇). 이름·캐릭터·맵은 전부 자체 제작이며 원작의 이름·그림은 쓰지 않는다.

v0.2 변경: 이름 확정(대난투 아레나), 브롤러 이름 확정(교행이·짬뽕이·소월이), 모드 2개(생존전 + 3:3 팀전).
v0.3 변경: 교행이를 칼 → **총잡이**로 변경 (모든 브롤러가 원거리 공격 가능).

---

## 1. 한 줄 요약

두 가지 모드를 고르는 3분짜리 난투.
- **생존전**: 6명이 각자 싸워 마지막까지 살아남기
- **3:3 팀전**: 나 + 아군 봇 2명 vs 상대 봇 3명, 먼저 10번 쓰러뜨리는 팀이 승리

왼손으로 움직이고, 오른손으로 조준해서 쏘고, 게이지가 차면 **필살기**를 쓴다.

## 2. 핵심 재미

| 재미 | 어떻게 만드나 |
|---|---|
| 손맛 있는 조준 | 오른쪽 조이스틱을 당겨 조준선을 보고 놓으면 발사, 그냥 톡 치면 가까운 적에게 자동 조준 |
| 숨고 기습하기 | 수풀에 들어가면 적에게 안 보임. 벽 뒤로 숨어 탄을 피함 |
| 성장 (생존전) | 맵의 상자를 부수면 **파워 큐브** → 체력·공격력 상승 |
| 팀플레이 (팀전) | 아군 봇이 나를 따라오고, 내가 노리는 적을 같이 공격 |
| 긴장감 | 생존전은 독구름, 팀전은 막판 동점 시 **서든데스** |
| 한 방 역전 | 맞히면 차는 **필살기** 게이지 |

## 3. 화면 흐름

```
초기 화면 ─┬─ 시작 → 모드 선택(생존전 / 3:3 팀전) → 브롤러 선택 → 매치 → 결과 → 처음으로 / 다시 하기
           ├─ 게임 설명
           ├─ 순위 보기 (이 폰의 기록 TOP 10, 모드별 탭)
           └─ 게임 선택 (작업실 메인으로)
```

- 초기 화면은 교행이의 모험·스타 슈터와 같은 구성: 제목 · 한 줄 설명 · 큰 **시작** 버튼 · 아래 같은 크기의 보조 버튼 3개.
- 매치 중 일시정지 버튼(Ⅱ) → 계속하기 / 처음으로.

## 4. 조작 (세로 화면)

```
┌──────────────────────────┐
│ 생존 6 · 02:41 · 큐브 3   │  ← HUD (팀전은  파랑 4 : 3 빨강 · 01:52)
│                          │
│        (게임 화면)        │
│                          │
│  ◯ 이동              ◎ 공격 │  ← 아래 1/3 어디든 손가락을 대면 그 자리에 조이스틱
│                   ★ 필살기 │
└──────────────────────────┘
```

- **이동**: 화면 왼쪽 아래 아무 곳이나 누르면 그 자리에 조이스틱이 생김 (스타 슈터 조이스틱 코드 재사용, 관성 없음).
- **공격**: 오른쪽 조이스틱
  - 톡 치기 → 가장 가까운 보이는 적에게 자동 조준 발사
  - 끌기 → 조준선 표시, 손을 떼면 그 방향으로 발사 (가운데로 되돌리면 취소)
- **탄약 3칸**: 한 번 쏘면 1칸 소모, 시간이 지나면 1칸씩 다시 참. 탄이 없으면 못 쏨.
- **필살기**: 적을 맞히면 게이지가 참. 가득 차면 ★ 버튼이 빛나고, 공격과 같은 방식으로 조준.
- PC: WASD 이동, 마우스 조준·클릭 발사, 우클릭/E 필살기.

## 5. 브롤러 (3명)

| 이름 | 역할 | 체력 | 속도 | 기본 공격 | 필살기 |
|---|---|---|---|---|---|
| **교행이** | 총잡이 (중거리 연사) | 4200 | 빠름 | **소총 4연발**: 직선으로 빠르게 4발 (중거리, 발당 350) | **총알 폭풍**: 앞으로 구르며 사방으로 총알 16발 난사 |
| **짬뽕이** | 투척 (범위 공격) | 3200 | 보통 | 벽을 넘어가는 **짬뽕 그릇** 던지기, 떨어진 자리 범위 피해 (900) | **불맛 폭탄**: 큰 그릇 — 바닥이 3초간 불바다 |
| **소월이** | 저격 (원거리) | 2800 | 보통 | 멀리 날아가는 **화살** 1발 (1100) | **관통 화살**: 벽과 적을 뚫고 지나가는 굵은 화살 |

- 셋 다 처음부터 선택 가능. 트로피를 모으면 **브롤러 레벨**이 올라 체력·공격력 소폭 상승 (최대 5레벨).
- 교행이는 교행이의 모험 주인공 얼굴에 소총을 든 모습을 탑뷰로 그림.
- 사거리: 교행이 중거리 · 짬뽕이 중거리(곡사, 벽 넘김) · 소월이 장거리. 교행이는 연사로 근접전에도 강하고, 소월이는 한 방이 크지만 연사가 느림.
- 숫자는 1차 값이며, 봇끼리 자동 대전시켜 승률을 보며 조정.
- 체력은 3초간 공격·피격이 없으면 초당 13%씩 회복.

## 6. 게임 모드

### 생존전 (6명 개인전)
- 나 + 봇 5명, 각자 싸움. 맵 약 30×30칸, 카메라가 내 브롤러를 따라감.
- 상자 10개 → 부수면 파워 큐브 1개 (큐브당 체력 +10%, 공격 +10%). 쓰러진 브롤러는 가진 큐브를 떨어뜨림.
- 1:00부터 독구름이 30초마다 한 겹씩 좁혀 옴. 안에 있으면 초당 1000 피해.
- 마지막 1명이 남거나 내가 쓰러지면 끝.

| 등수 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 트로피 | +10 | +7 | +4 | +1 | −2 | −4 |

### 3:3 팀전 (나 + 아군 봇 2 vs 적 봇 3)
- 맵 약 20×30칸, 양 끝에 팀별 출발 지점. 상자·큐브 없음.
- 쓰러지면 **3초 뒤 출발 지점에서 부활**.
- 상대를 **먼저 10번** 쓰러뜨린 팀이 승리. 3분이 지나면 처치 수가 많은 팀 승리, 동점이면 **서든데스**(다음 처치가 결정).
- 아군 봇은 파란 테두리, 적은 빨간 테두리. 아군끼리는 공격이 안 맞음.

| 결과 | 승리 | 무승부 | 패배 |
|---|---|---|---|
| 트로피 | +8 | 0 | −3 |

- 내가 가장 많이 처치하면 **MVP** 표시 + 트로피 +2.

## 7. 맵

- 타일 기반 (1칸 = 브롤러 지름 정도).
  - **벽**: 이동·탄 막힘 (짬뽕이 그릇은 넘어감, 필살기로 부서질 수 있음)
  - **수풀**: 들어가면 적에게 안 보임 (가까이 오거나 공격하면 보임)
  - **물**: 이동 막힘, 탄은 통과
  - **상자**: 체력 있음, 부수면 큐브 (생존전만)
- 맵은 문자열 배열로 적어 `maps.js`에 둠 → 새 맵 추가가 쉬움.
- 모드별 맵 1개씩으로 시작, 이후 추가. 팀전 맵은 좌우 대칭으로 만들어 공평하게.

## 8. 봇 AI

상태 머신으로 단순하게. 두 모드가 같은 봇을 쓰고 "누가 적인가"만 다름.

- **배회** → 상자가 보이면 **상자 부수기**, 적이 보이면 **교전**
- **교전**: 자기 사거리에 맞춰 거리 유지(소월이는 멀리, 교행이는 중간 거리, 짬뽕이는 벽 뒤에서), 탄 모아서 쏘기, 좌우로 무빙
- **도망**: 체력 30% 이하면 수풀/벽 뒤로 후퇴해 회복
- **독 피하기**(생존전): 독구름 경계가 가까우면 안쪽으로 이동
- **팀 행동**(팀전): 아군 봇은 플레이어 근처를 따라다니다 플레이어가 공격하는 적을 우선 공격. 적 봇은 체력 낮은 목표를 함께 노림
- 난이도 = 반응 속도 · 조준 오차 · 공격 빈도 (트로피가 오를수록 봇도 강해짐)

## 9. 진행·기록

- **트로피**: 이 폰에 저장. 두 모드의 트로피를 합쳐 브롤러 레벨에 반영.
- **순위 보기**: 모드별 TOP 10, 이 폰에만 저장.
  - 생존전: 등수 · 처치 수 · 브롤러 · 날짜
  - 팀전: 승/패 · 팀 점수(예: 10:7) · 내 처치 수 · 브롤러 · 날짜
- 나중에 원하면 네온 블록처럼 온라인 순위(Firebase) 추가 가능.

## 10. 화면·연출

- 밝고 만화 같은 색: 진한 남보라 배경 + 노랑 강조, 굵은 글씨.
- 캐릭터는 그림 파일 없이 캔버스로 그림 (동그란 몸 + 무기 + 팀 색 테두리), 머리 위 이름·체력바·탄약 칸.
- 피격 시 흰색 번쩍, 숫자 튀어오르기, 화면 살짝 흔들림, 효과음은 합성음(파일 없음).

## 11. 파일 구조 (유지보수용으로 나눔)

```
brawl-arena/
  index.html   화면 뼈대 (HUD, 캔버스, 메뉴 패널)
  style.css    스타일
  main.js      시작점: 메뉴 · 화면 전환 · 순위 저장 · 확대 막기
  PLAN.md      이 기획서
  ── 1단계부터 추가 ──
  config.js    숫자 모음 (브롤러 능력치, 트로피 표, 독구름·부활 시간)
  brawlers.js  교행이·짬뽕이·소월이의 공격·필살기 동작
  modes.js     생존전 / 팀전 규칙 (승리 조건, 부활, 독구름)
  maps.js      맵 데이터
  game.js      매치 진행 (업데이트 루프, 충돌, 피해)
  bot.js       봇 AI
  input.js     두 개의 조이스틱 + 키보드/마우스
  render.js    그리기 순서 (카메라, 탄, 이펙트)
  art.js       생김새 (사람 캐릭터, 바위·돌담·나무상자, 연못, 풀밭)
  sound.js     효과음
  game.test.mjs 규칙 테스트 (피해 계산, 충돌, 승리 조건)
```

- 규칙(game.js·modes.js)과 그리기(render.js)를 분리 → 봇끼리 자동 대전 테스트 가능.
- 밸런스 숫자는 `config.js` 한 곳에서만 고침.

## 12. 개발 단계

| 단계 | 내용 | 확인 방법 |
|---|---|---|
| **0 (완료)** | 폴더·초기 화면·기획서 | 메뉴 버튼 동작 |
| **1 (완료)** | 교행이 1명, 이동·조준·공격·탄약, **3:3 팀전**(부활·10처치 승리), 봇 AI 기본 | 봇끼리 100판 자동 대전이 끝까지 돌아감 |
| **2** | 짬뽕이·소월이, 필살기, 수풀, 모드·브롤러 선택 화면, 결과·트로피·순위 | 브롤러별 승률이 크게 치우치지 않는지 |
| **3** | **생존전**(상자·큐브·독구름), 효과음·이펙트, 브롤러 레벨 | 한 판 3분 안팎으로 끝나는지 |
| **4 (선택)** | 맵 추가, 온라인 순위 | — |

- 팀전을 먼저 만드는 이유: 부활이 있어 테스트하기 쉽고, 봇 AI를 그대로 생존전에 쓸 수 있음.
